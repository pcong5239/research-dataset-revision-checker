HOW IT WORKS

Make a dataset revision easy to inspect

1. Gather the references

You need a public dataset landing page and its canonical repository, plus the version and license you expect to see.

2. Register and freeze

Choose Connect wallet, select a wallet in the picker, complete the connection, then register the bounded references. Choose Freeze when the case is ready for review.

3. Assess the case

Choose Assess to let the contract compare the two required sources. A source that cannot be reached remains unresolved and can be retried with Retry unresolved.

4. Verify the result

Wait for the confirmation message, then read the saved case details. Completion is shown only after the transaction and the saved details agree. A transaction link is provided for independent verification.

The contract stores bounded references and normalized evidence digests, not the source bodies. If a wallet request is cancelled or a network check is interrupted, the page explains the next safe action and never submits the same request automatically.
